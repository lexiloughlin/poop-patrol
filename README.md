# Poop Patrol 🐹

A maze game starring my four guinea pigs: Toki, Mochi, Poke, and Miso Soup.

Pick your pig, then gobble up every poop pellet in the cage before the robot vacuums catch you. Grab a hay bundle to get the zoomies, which scares the vacuums so you can bonk them for bonus points.

## How to play

- **Move:** arrow keys or WASD. On a phone, swipe or use the on-screen pad.
- **Pause:** P
- **Poop pellet:** 10 points
- **Hay bundle:** 50 points, plus the vacuums get scared for a few seconds
- **Bonking a scared vacuum:** 200, then 400, then 800 points
- **Clearing the cage:** 500 bonus points, and the next cage is faster
- You have 3 hearts.

## Run it

It's a single `index.html` file with no build step. Open it in any browser, or play it online through GitHub Pages.
